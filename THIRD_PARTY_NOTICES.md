# Third-party components

CiteFlow uses dependencies installed by npm; original license files remain with those packages.

- **citeproc-js / citeproc**: scholarly citation processor; CPAL-1.0 OR AGPL-1.0 as declared by its package. Repository: https://github.com/Juris-M/citeproc-js
- **Citation.js core and CSL plugin**: supplies integration and bundled styles/locales. Repository: https://github.com/citation-js/citation-js
- **Citation Style Language styles and locales**: community-authored formatting definitions; see their embedded attribution/license metadata and https://citationstyles.org/ for source repositories and licensing.
- **Cheerio**, **JSZip**, **@xmldom/xmldom**, **ipaddr.js**, **Zod**, and the **Model Context Protocol TypeScript SDK**: see each installed package's license.

No third-party full-text publications are bundled. Test metadata is synthetic except the public DOI used in documented lookup examples. The package is marked private to prevent accidental npm publication. No open-source license for newly authored project code has been selected on behalf of the repository owner.
